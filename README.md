One letter for a day that wrung you dry: **X**, standing for the hidden word **"eXhausted"**. It is vivid — a whole day of running on empty, summed up in a single crossed-out letter. It is funny and surprising, because X is the sharp, unobvious initial for the "ex-" word, not the easy A-amazing, F-Friday or Z-zero-sleep pick the rules themselves hand you. And it is true: everyone has had the day where the only honest word left is exhausted, and the letter X even looks wiped out. The program writes exactly that one character, `X`, to `/output/entry.txt` — no word, no gloss, no punctuation — and then reads it back to prove it is a single A–Z letter before finishing.

## Run it

```sh
node main.ts
```
